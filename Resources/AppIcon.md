# App icon

`AppIcon.png` is the generated master artwork, with an alpha channel. The macOS build converts it into the standard 16–1024 px icon representations and bundles `AppIcon.icns`. It is used as the application icon; the menu bar retains its monochrome system symbol.

Created with the built-in image generation tool on 2026-10-08. No API credentials are required by the build.

## Generation prompt

Use case: logo-brand. Create one finished macOS app icon for Crypto Monitor, a personal market-chart menu bar application focused on ETH, BTC and macro markets. Asset type: production app icon, square 1024 by 1024 canvas, isolated on genuinely transparent surroundings. A single centered dark midnight-navy rounded-square macOS tile with generous equal transparent margins (tile occupies about 84% of canvas), subtle glass and satin depth, crisp polished edges, restrained soft shadow. Inside the tile, an elegant compact geometric emblem combining an Ethereum-like faceted diamond in pale ice blue with three simple cyan/mint trading candlestick forms, integrated into one strong balanced silhouette. Refined professional financial instrument aesthetic, luminous but not neon. Match the app palette: navy #101c2a and #142335, ice #edf3fa, blue #7eb3ff, mint #65d6bd. Central emblem is bold and readable at 32px; avoid fine texture and tiny details. Straight-on orthographic view, no perspective. No text, no letters, no numbers, no coin circle, no Bitcoin logo, no arrows, no red/green buy/sell signals, no surrounding mockup, no extra objects. Output exactly one icon.
