# Crypto Monitor

个人 macOS 菜单栏行情工具。默认覆盖 BTC/USD、ETH/USD、10 年及 30 年美国国债收益率、Binance XAUUSDT 黄金永续，可手动添加其他 Binance USDT 永续资产。仅展示行情。

## 界面方向

原生菜单栏加紧凑的交易工作台。图表是视觉中心，资产共用可横向滚动的自选栏，右侧保留添加入口。左侧展示当前品种与价格，右侧提供区间和来源时间。默认中文。

- 背景：深海蓝 `#101c2a`；图表画布 `#142335`；悬浮层 `#1c3045`。
- 文本：冰白 `#edf3fa`；辅助文本 `#9fb1c5`。
- 强调：钴蓝 `#7eb3ff`；上涨青色 `#65d6bd`；下跌珊瑚红 `#ff8e99`。
- 排版：macOS 系统字体用于操作与正文，圆角系统数字用于价格，等宽数字便于扫描。
- 布局：菜单栏 → 顶部操作栏 → 横向自选 → 当前品种摘要 → 图表操作 → K 线及成交量 → 来源状态。
- ETH 首页在当前价格与图表操作之间增加约 90 pt 的五列指标摘要，价格 K 线和成交量继续作为首页主体；点选摘要进入同一弹窗二级详情，其他品种不增加此栏。
- 交互：周期切换、十字线 OHLC、缩放、拖动、SMA20/SMA50、成交量、重置视图、保持弹窗、菜单栏品种选择。
- K 线详情浮窗沿用蓝灰色面板与等宽数字，悬停时避开光标和图表边界；点击可固定，显示本根开高低收、涨跌和成交量。上方 OHLC 与浮窗保持同一根 K 线。
- 弹窗目标高度为 900 pt，按菜单栏所在屏幕可用高度限制；顶部信息区维持原尺寸，把新增空间交给图表。

复核：大数字是行情工具的核心读数，保留；移除营销标题、装饰渐变和重复卡片，把视觉强调集中于真实交易图表。涨跌配合符号、数值，不能只靠颜色。

## 数据与边界

- Coinbase 公共接口提供 BTC/ETH 美元报价和真实 OHLCV，涨跌基准为滚动 24 小时。
- Yahoo Finance 的 `^TNX` / `^TYX` 为美债收益率指数，单位 %，日变动以 bp 展示；不是债券或美债期货的价格。
- 黄金统一为 Binance `XAUUSDT` USDT 永续，报价来自 `ticker/24hr.lastPrice`，K 线来自同合约 `klines`，使用滚动 24h 涨跌。标记价、指数价不作为主价格；不再使用 COMEX `GC=F`。
- Yahoo 为非正式公共接口，可能限流或变更；页面展示来源、时间和延迟提示。
- 美债收益率只开放日线与周线，无成交量，涨跌基准为上一交易日收盘。
- BTC/ETH、黄金和新增永续提供 60 秒原生 K 线。分钟图约每 15 秒检查更新，报价为定时轮询而非逐笔推送。
- 网络失败保留本地最后一次成功数据，并显式标注缓存；首次无数据则显示错误及重试，不生成模拟行情。
- 历史为有限窗口（Coinbase 最多约 300 根，Binance 永续最多 1,000 根，美债按周期覆盖不同区间），不声称无限历史；新合约只展示上市后的实际数据。
- 主页与菜单栏共用设置中的勾选，默认显示 BTC 和 ETH。取消勾选仅隐藏，保留资产定义，至少保留一个显示品种；快捷键仅按可见资产顺序切换。“登录时启动”由设置开关控制，首次安装不自动注册。

## 实现

Swift AppKit 的 NSStatusItem / NSPopover 负责 macOS 行为，WKWebView 加载应用内置的 TypeScript 界面。Swift URLSession 获取行情，无本地后台服务、无 API key。TradingView Lightweight Charts 5 渲染真实 K 线；保留许可证与归属链接。应用在本地构建；2026-10-09 用户授权将源码推送到 `ethen-lee` 个人私有仓库，不发布应用安装包。

Swift `Asset` 提供资产定义，包含稳定 ID、来源、真实 symbol、基币和 tickSize；前端从原生读取同一份列表。五个默认资产 ID 保持不变，自选 ID 为 `binance:perpetual:<symbol>`，通过 UserDefaults 持久化。新增时使用公共 `exchangeInfo` 校验 `TRADING`、USDT 报价/保证金与 `PERPETUAL` / `TRADIFI_PERPETUAL` 类型；目录缓存 5 分钟，支持刷新，不接受任意 URL 或未经校验的 symbol。重复添加幂等，新增资产默认加入显示选择，内置资产不可移除。

沿用 UserDefaults 的 `menuAssets` 作为主页与菜单栏共同的显示选择，启动、修改勾选、添加和移除都应用该选择，保留用户已有勾选。隐藏或移除当前资产时切到第一个仍显示的品种，同时清除原图表、固定 K 线和旧请求上下文；若正在 ETH 研究页则返回行情。移除最后一个显示资产时恢复 BTC。未显示资产的报价异常不影响主页的连接状态。

报价与历史缓存键为来源、市场、交易对（及周期），仅迁移口径未变的旧数据，COMEX 黄金旧数据不会作为 XAUUSDT 缓存回退。新增资产的价格精度来自 `PRICE_FILTER.tickSize`；图表和菜单栏都保留低价资产所需小数位。行情客户端最多 3 个并发请求，HTTP 429/418/403/451 遵守 Retry-After 并退避，不绕过访问限制。

TradingView 品种映射由 Swift Asset 统一维护，通过 ready 和自选变更结果提供给前端。底部链接携带 symbol 与 interval，原生导航拦截把内置 TV 标志的首页地址转换为同一资产图表。美债外链对应 TVC US10Y/US30Y 收益率，黄金和新增永续对应 `BINANCE:<symbol>.P`。

登录自启动使用 `SMAppService.mainApp` 注册/注销；状态从 macOS 读取，区分 enabled、notRegistered、requiresApproval、notFound。待授权时提供系统登录项入口，不重复注册来绕过系统禁用。打开设置、打开弹窗以及应用恢复活动时刷新系统状态。根据启动 Apple Event 识别登录启动，保持弹窗关闭；普通启动保留现有打开行为。

## ETH 观察第一阶段

2026-10-08 用户确认采用以趋势为目的的方案，接受 Binance 公共数据作为市场参考，并要求观察起点支持手动日期和默认值。范围不含下单、账户授权、综合预测评分、ETF/新宏观数据、全市场多空比或内置分布热力图。

用户最新要求将合约观察放在二级页面，不再使用独立窗口。菜单栏弹窗默认展示原来的 Coinbase 行情；ETH 工具栏的「ETH 合约观察」在同一 WKWebView 内切换到观察页，隐藏自选栏以增加图表高度。左上角返回行情，Esc 先解除固定详情、再返回上一级、最后关闭弹窗。观察主图为 Binance ETHUSDT 永续成交价格，明确另列标记价和指数价。默认 4h，另有 1h、日线；价格历史分别约 180、60、730 天。观察工作台沿用深蓝画布，紧凑的三列读数加主图和最多两张联动副图；不把全部指标堆入同一页。

| 视图 | 副图 | 派生口径 |
| --- | --- | --- |
| 趋势与强弱 | ETHBTC 直接现货价格、ETHUSDT/BTCUSDT 现货涨幅 | 同一 UTC 起点后第一根共同 K 线的各自开盘价作为基准，只比较双方共同且已收盘的周期 |
| 杠杆与费率 | OI 数量 ETH、当前周期内实际已结算费率合计 | OI 期末存量不求和；较上一期变化须连续。7/30 天累计是返回记录费率的和；8h 等效 = 7 天和 / 21 |
| 主动成交 | 现货和永续 CVD，或分别展示主动买卖量 | 主动买量取 kline[9]，卖量 = kline[5] − kline[9]；CVD 从观察起点累加买减卖，不用涨跌分色推测主动方向 |
| 波动风险 | Wilder ATR14 日线 | TR = max(高−低, abs(高−昨收), abs(低−昨收))；前 14 个 TR 均值为种子，之后 (前 ATR×13+本 TR)/14 |

观察起点默认 UTC 今日减 30 天，可选近 7 天或手动日期。预设滚动，手动固定且持久化；手动日期不能在未来，空值或非法偏好恢复默认。起点控制相对涨幅、CVD 与重置视图，资金费 7/30 天累计独立于此。日期超出历史覆盖时显示实际起点与不足提示。只用获取当时已收盘的 K 线计算累计指标，过期缓存中的未收盘 K 线不会随着墙上时间自动变成已收盘数据。CVD 在缺口处停止；折线显示缺口，不把空值补零。

资金费情景单独弹窗：固定假设名义本金，未来每天重复最近 24h 已返回记录的累计费率，计算 7/30 天金额。假设、正负支付方向及局限在同一弹窗中显示。当前未结算费率不混入历史合计；样本不足或过期不计算情景。累计费率不等于实际调仓账户的费用。

清算价、入场价、链上成本分布目前仍为解释和外站入口，尚未满足用户最新提出的本地分布图要求。CoinGlass 清算热力图深链 `?coin=ETH` 已在网页确认选择 Binance ETH/USDT 永续；Hyblock 与 Glassnode 仍需自行选择品种。CoinGlass 和 Hyblock 的模型、Glassnode 的链上成本模型均不冒充完整真实仓位账本。

### 分布图接入核实与待办

2026-10-08 核实 [CoinGlass 清算热力图 Model 1](https://docs.coinglass.com/reference/liquidation-heatmap)：官方 API 仅 Professional / Enterprise 可用，支持 12h、24h、3d、7d、30d、90d、180d、1y；返回价格层、时间/价格索引对应的模型强度及配套 K 线。官网普通浏览出现登录提示，关闭后未获得可用图表；没有据此承诺免费嵌入或离线复制。网页 Prime 与 API 权限分开，未采购任何套餐。

[Hyperliquid 仓位接口](https://docs.coinglass.com/reference/hyperliquid-position) 提供入场价、清算价、方向、数量、名义金额和更新时间，需 Standard / Professional / Enterprise API 权限。文档未证明地址覆盖全量，不可称作全市场或平台全量仓位。尚未核实 CoinGlass 可提供 ETH 链上成本分布，不能用其 Volume Profile 顶替。

用户了解付费要求后决定不接入付费 API，分布图本地重绘暂不实施。以下为保留的设计备选，不属于已实现功能：同一二级观察页面的独立「分布」视图，清算热力图以时间 × 价格为主画布，配同源 K 线、强度图例及选定时点的价格分层柱；入场价按长短方向分开，显示样本地址数、覆盖范围和采样时间；链上成本视图标明模型、单位与更新时间。默认观察 30 天，支持 7/30/90 天和鼠标选取时间切片。当前价格附近区间和完整价格范围可切换，缺失区域不画成零。颜色沿用深蓝画布、青色/珊瑚红方向色，热度使用独立单调亮度色阶；主要空间留给图，不堆新增读数卡片。

没有 API 权限时，官方网页只能作为在线查看方式，仍遵守其登录和订阅要求；这不等同于取得本地重绘数据。取得授权后才增加原生数据适配与密钥保管，密钥不放前端、日志或仓库。

## 观察数据实现

- `ResearchData.swift` 的独立 actor 复用原生 URLSession/JSON 文件缓存方式，无服务器、数据库或 API key。键包含平台、市场数据集、symbol、interval，不能拼接不同市场曲线。元信息包含来源、市场/合约、统计周期、单位、报告属性、源时间语义、源时间、获取时间、缓存/异常状态；原始 OI 同时保留数量和名义金额，首期图上仅用数量。
- `App.swift` 保持一个 NSPopover / WKWebView，提供白名单数据集桥接、当前页面的 TradingView 上下文、白名单供应商外链及后台 4h OI 积累。观察页进入/返回更新当前图表上下文，TV 标志始终对应当前页面的市场与周期。新缓存 `research-cache-v1.json` 与原 `market-cache.json` 分离，旧缓存格式和菜单栏价格不变。
- `research-model.ts` 定义派生指标；`research-store.ts` 为摘要与详情共用的数据状态，合并请求、错误、加载及刷新间隔；`market-summary.ts` / `.css` 渲染紧凑摘要及共享详情读数。`research.ts` 管理观察视图与关注副图，`main.ts` 管理页面路由并在返回时恢复主图时间范围；不重建原价格图。
- 首页固定窗口：ETH/BTC 最新已收盘 1h 价格与 168h 前比较；1h OI 数量与 24h 前比较，必须精确命中时间点。资金费近 7 天取实际结算记录之和，不混入参考预测费率。现货与永续主动买入占比使用双方较早获取时间之前的同一个完整 24h 窗口，累加量后相除，任一市场缺小时或总量为零则该市场为空。ATR 占比取共享完整日线历史的 Wilder ATR14 / 收盘价，较前日用百分点；不使用短窗口重新播种。
- 摘要不继承行情周期或观察起点。点选摘要切到对应观察页签并标亮副图，但保留观察周期和日期；顶部复用首页读数并列明固定窗口，「本轮读数」恢复原有起点统计。每项单独判断覆盖与过期，获取失败和覆盖不足互不替代；资金费覆盖按记录边界与 >12h 可疑间隔检查，是保守检查而非完整账本证明。
- `researchCached` 只读桥接沿用原生缓存键和格式；首次展示先取缓存，再按 TTL 补刷。首页六组数据沿用完整历史窗口（ratio/spot/perpetual 1h、interest 1h、funding、perpetual 1d），没有另存会缩短详情历史的摘要缓存。切页复用正在进行的请求，晚返回的数据只更新共享状态，不改变用户页面。
- 初次 K 线分页回补，之后重叠更新末尾；OI 以不超过 500 条的时间块读取约 29 天安全窗口，历史样本在本地最多保留 2 年。资金费初次 90 天、逐次结算时间和类型去重，区分同一时间的普通/特殊结算。
- 前端非日线价格和参考快照 TTL 60 秒；OI、资金费、日线 TTL 300 秒。应用每 5 分钟积累 4h OI，其他周期随查看积累。摘要仅在首页 ETH 可见时轮询，关闭弹窗停止前端定时刷新，已发出的请求可完成并缓存；打开/休眠恢复后补刷，跨出源历史窗口不伪造连续历史。原生退避仍约束手动刷新，前端首次无数据失败也至少间隔 60 秒才自动重试。
- 每个数据键合并并发请求，全局最多 3 个网络请求。普通失败指数退避 30 秒至 8 分钟；429 至少 60 秒，418/403/451 至少 1 小时，同主机暂停并尊重更长的 Retry-After。手动刷新不绕过退避，也不更换地区域名绕过限制。
- 原生保留成功缓存，失败附错误；前端另检查获取时间与源时间是否滞后。首次无数据展示空状态/重试。副图独立返回，某项失败不遮盖其他已取得的数据；过期项和统计窗口不足可在数据口径弹窗追溯。

接口定义以 [Binance USDⓈ-M 官方市场数据文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data) 与 [现货文档](https://developers.binance.com/en/docs/catalog/core-trading-spot-trading/api/rest-api/market) 为依据；接口条款、历史保留与地域可用性可能变化。
